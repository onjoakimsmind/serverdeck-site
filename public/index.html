02 Built for one machine

The host is the
source of truth.

There is no agent to deploy, no fleet to reconcile, and no second copy of your infrastructure to keep honest. ServerDeck lives on the host it describes.

  • Bundled runtime

    FrankenPHP, a static PHP CLI, the host helper, and PAM tooling ship in the release. No system PHP, Node, nginx, or Composer required.

  • A narrow privileged path

    The web process runs unprivileged. Root actions go through one no-argument sudo rule and a validated, allow-listed helper.

  • Your accounts, not another password

    Authentication goes straight to Linux PAM. ServerDeck never stores application passwords.

03 Get on deck

One command.
A deck on the other side.

Run this on the Linux host you want to manage. The bootstrap resolves the latest stable release, verifies its published SHA-256 checksum, and then starts the installer.

Terminal SHA-256 verified
$ curl -fsSL https://serverdeck.black.ax/install.sh | sh
Runs with sudo. x86_64 Linux only.
Need a workload? curl -fsSL https://serverdeck.black.ax/install.sh | sh -s -- --workloads incus,docker
  1. 01
    Resolve the release

    The latest stable tag is read from GitHub. No credentials needed.

  2. 02
    Verify the archive

    The tarball is checked against the release’s SHA-256 before extraction.

  3. 03
    Install the deck

    A self-contained release lands in /opt/serverdeck, with systemd units and a CLI.

  4. 04
    Open your host

    The installer prints the panel URL. Sign in with an existing Linux account that uses sudo.
